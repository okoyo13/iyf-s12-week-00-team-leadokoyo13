# Essential VS Code Keyboard Shortcuts

This guide covers essential keyboard shortcuts for developers using Visual Studio Code on Windows.

## 1. Editing Code

| Shortcut                | Action                           |
| ----------------------- | -------------------------------- |
| `Ctrl + S`              | Save the current file            |
| `Ctrl + Z`              | Undo the last action             |
| `Ctrl + Y`              | Redo the last action             |
| `Ctrl + X`              | Cut selected text                |
| `Ctrl + C`              | Copy selected text               |
| `Ctrl + V`              | Paste copied text                |
| `Alt + Up/Down`         | Move the current line up or down |
| `Shift + Alt + Up/Down` | Copy the current line up or down |
| `Ctrl + /`              | Toggle line comments             |
| `Shift + Alt + F`       | Format the current document      |

## 2. Navigation and Search

| Shortcut           | Action                        |
| ------------------ | ----------------------------- |
| `Ctrl + P`         | Quickly open a file           |
| `Ctrl + Shift + P` | Open the Command Palette      |
| `Ctrl + F`         | Find text in the current file |
| `Ctrl + H`         | Find and replace text         |
| `Ctrl + Shift + F` | Search across project files   |
| `F12`              | Go to a symbol's definition   |

## 3. Working with the Editor

| Shortcut           | Action                      |
| ------------------ | --------------------------- |
| `Ctrl + N`         | Create a new file           |
| `Ctrl + W`         | Close the current editor    |
| `Ctrl + Tab`       | Switch between open editors |
| `Ctrl + B`         | Show or hide the sidebar    |
| `Ctrl + \`         | Split the editor            |
| `Ctrl + Shift + E` | Open the Explorer panel     |
| `Ctrl + Shift + X` | Open the Extensions panel   |

## 4. Terminal and Debugging

| Shortcut           | Action                               |
| ------------------ | ------------------------------------ |
| `` Ctrl + ` ``     | Show or hide the integrated terminal |
| `F5`               | Start or continue debugging          |
| `Ctrl + Shift + D` | Open the Run and Debug panel         |
| `Shift + F5`       | Stop debugging                       |

## 5. Best Practices

- Learn the shortcuts you use most frequently.
- Use formatting tools to maintain consistent code style.
- Use the Command Palette when you cannot remember a command.
- Follow the keyboard shortcuts configured for your operating system.
- Check the official documentation for additional shortcuts.
